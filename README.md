# Caesar Cipher Tool Online

An easy-to-use **Caesar Cipher encoder and decoder** made with HTML, CSS, and JavaScript.  
It’s designed for learning, experimenting, and playing with one of the oldest and simplest encryption techniques in history.

## 🔹 Features
- **Encrypt** any text with your chosen shift value (0–25).
- **Decrypt** manually or try all possible keys with **Auto Decrypt**.
- **Interactive frequency analysis chart** to visualize letter distribution in your text.
- **Instant preview** — results update as soon as you encrypt or decrypt.
- **Reset button** to quickly start fresh.

## 🔹 How It Works
The Caesar Cipher shifts each letter by a fixed number of positions in the alphabet.  
Example: with a shift of `3`, `A` becomes `D`, `B` becomes `E`, and so on.
